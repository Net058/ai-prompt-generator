# AI Cinematic Prompt Generator

A lightweight Python tool designed to generate cinematic
prompts for generative AI video platforms.

## Overview

This project transforms simple scene descriptions into
structured cinematic prompts by combining camera movements,
lighting techniques, and visual styles.

## Features

- Dynamic cinematic prompt generation
- Multiple camera movement techniques
- Custom lighting and visual styles
- Interactive command-line interface
- No external dependencies or paid APIs

## Technologies

- Python 3
- Python Standard Library
- Git and GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Net058/ai-prompt-generator.git
cd ai-prompt-generator
python3 app.py
```

## Example

Input:

> A futuristic city at night

Possible output:

> A futuristic city at night, smooth tracking shot,
> neon atmospheric lighting, futuristic sci-fi,
> realistic motion, high detail, cinematic composition,
> 4K resolution, 24 fps.
